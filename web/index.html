Privacidade & limites

• Hash streaming 4MB gerado localmente; o hash (não o arquivo) é enviado ao VT na consulta. Sem localStorage, beforeunload: purge.
• VT só tem resultado se alguém já enviou; arquivo novo → 404 / No comments é normal. Acima de >650MB o VT não é consultado.
• horash.bat inicia o app via python.exe assinado (bypass do Smart App Control); o botão VT anônimo abre o navegador em --incognito real.

Como funciona

01 — Hash local

Arraste arquivos para a bandeja. O hash SHA-256 é gerado no seu dispositivo com streaming 4MB (<50MB via WebCrypto, ≥50MB via js-sha256) — funciona para GBs sem estourar RAM. O arquivo não sai do PC; apenas o hash vai ao VT.

02 — Verify no VirusTotal

Se ≤650MB: o hash é consultado automaticamente — com API key mostra X / 72 na tabela; sem key usa Playwright no site do VT. O botão VT anônimo abre o relatório em aba anônima via server.py. >650MB: o app não consulta o VT.

03 — Scan local

O app envia para POST /scan local e roda ClamAV (até 2000MB) + YARA. Resultado ✓ Limpo, ⛔ Infectado ou ⚠️ Parcial quando um engine falha/é ignorado. Acima de 2GB o ClamAV não roda. Temp deletado após o scan.

Privacidade

Sem localStorage, sem cookies. Fechar a aba limpa files e apiKey. Para anônimo real, rode horash.bat.
