Como funciona

01 — Hash local

Arraste arquivos para a bandeja. O app gera SHA-256 no seu dispositivo com streaming 4MB (<50MB via WebCrypto, ≥50MB via js-sha256) — funciona para GBs sem estourar RAM. Nada sai do seu PC.

02 — Verify no VirusTotal

Se ≤650MB: VT anonimo abre virustotal.com/gui/file/{hash} em anônima (1 clique via server.py), ou com API key mostra X / 72 dentro da tabela. >650MB o VT não aceita — use Scan Local.

03 — Scan local sempre

Após o hash, o app envia para POST /scan local e roda ClamAV (2000M) + YARA (server.py + scanner.py). Resultado ✓ Limpo / ⛔ Infectado com ClamAV + YARA + tempo. Temp deletado após scan.

Privacidade

Sem localStorage, sem cookies. Fechar a aba limpa files e apiKey. Para anônimo real, rode FileHasher.bat.
